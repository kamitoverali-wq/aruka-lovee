ARUKA CONFESSION — FINAL
==========================
Откройте index.html в браузере.

Структура:
- index.html — сайт
- bir_oilap_alam.mp3 — песня Abzal Uteshov — Bir Oilap Alam
- photos/ — 9 фотографий

Музыка запускается кнопкой «Включить нашу песню», потому что современные браузеры обычно запрещают автоматическое воспроизведение звука без действия пользователя.

Примечание:
Первые пять фотографий взяты из сохранённых материалов проекта. Если позже захочешь заменить любую из них на другую фотографию, достаточно заменить соответствующий файл в папке photos, сохранив его имя.
